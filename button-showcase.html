🔥 Effect Details

Primary Button Effects (✨ Shimmer):

  • Shimmer on Hover: White gradient sweeps left to right
  • Continuous Glow: Pulsing shadow animation (3s loop)
  • Hover Transform: Lifts 4px + scales to 102%
  • Color Shift: Gradient intensifies (purple to pink)
  • Click Ripple: Radial burst animation from click point
  • Active Press: 3D press-down effect (scale 98%)

Secondary Button Effects (🔮 Magnetic Border):

  • Magnetic Border: Animated gradient border on hover
  • Glassmorphism: Backdrop blur with transparency
  • Glow Shadow: Soft purple shadow appears on hover
  • Color Change: Text shifts to accent color
  • Inner Glow: Subtle inset shadow effect
  • Smooth Transitions: Cubic-bezier easing (0.4s)

Alternative Button Styles:

  • Liquid (💧): Gradient fills from bottom to top on hover
  • Neon (🌟): Continuous pulsing glow with intensified hover
  • Morph (🎨): Animated gradient constantly shifting position
  • Glitch (⚡): RGB split chromatic aberration on hover
  • Bubble (🫧): Playful scale bounce animation
  • Split (🔄): Dual-panel gradient slides in from sides

Universal Effects:

  • Focus Pulse: Expanding ring animation for accessibility
  • Particle Burst: ✨ emoji scales and fades on active
  • Ripple Effect: Click creates expanding white circle
  • 3D Press: Physical button press sensation
  • Smooth Easing: Cubic-bezier for natural motion

💡 How to Use Different Button Styles

Simply add the style class to any button element:

<button class="button primary">Shimmer Effect</button>
<button class="button liquid">Liquid Fill</button>
<button class="button neon">Neon Glow</button>
<button class="button morph">Morphing Gradient</button>
<button class="button glitch" data-text="Text">Glitch Effect</button>
<button class="button bubble">Bubble Pop</button>
<button class="button split">Split Reveal</button>
