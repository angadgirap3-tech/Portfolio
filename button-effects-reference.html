⚡ Quick Button Reference

Copy and paste these button snippets into your HTML. Click any button to see it in action!

💡 Pro Tips

  • Use .primary for main CTAs and important actions
  • Use .secondary for alternative options
  • Mix effects based on context and importance
  • Test in both light and dark modes
  • Limit to 2-3 different styles per page
  • All buttons work with keyboard navigation
  • Mobile responsive by default

🚀 Ready to Use

All button effects are ready to use in your portfolio. Simply add the appropriate class to any button or anchor element!
