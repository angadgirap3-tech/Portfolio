## 🚀 Quick Reference

| Button Style | Class | Best For | Key Effect |
|-------------|-------|----------|------------|
| ✨ **Shimmer** | `.button.primary` | Primary CTAs | Light sweep animation |
| 🔮 **Magnetic Border** | `.button.secondary` | Secondary actions | Gradient border on hover |
| 💧 **Liquid Fill** | `.button.liquid` | Form submissions | Bottom-up fill |
| 🌟 **Neon Glow** | `.button.neon` | Dark themes | Pulsing light effect |
| 🎨 **Morphing** | `.button.morph` | Dynamic content | Animated gradient shift |
| ⚡ **Glitch** | `.button.glitch` | Tech/Creative | RGB chromatic split |
| 🫧 **Bubble Pop** | `.button.bubble` | Playful UI | Scale bounce |
| 🔄 **Split Reveal** | `.button.split` | Premium actions | Dual-panel slide |

---

## 📝 Usage Examples

```html
<!-- Primary with shimmer effect -->
<button class="button primary">Get Started</button>

<!-- Secondary with magnetic border -->
<button class="button secondary">Learn More</button>

<!-- Liquid fill effect -->
<button class="button liquid">Submit</button>

<!-- Neon glow effect -->
<button class="button neon">Play Now</button>

<!-- Morphing gradient -->
<button class="button morph">Explore</button>

<!-- Glitch effect (needs data-text attribute) -->
<button class="button glitch" data-text="Hack">Hack</button>

<!-- Bubble pop effect -->
<button class="button bubble">Pop!</button>

<!-- Split reveal effect -->
<button class="button split">Reveal</button>
```
